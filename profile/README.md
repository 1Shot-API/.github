## Products

| | |
| --- | --- |
| **[1Shot Wallet](https://www.1shotapi.com/solutions/1shot-wallet)** | Permissionless, non-custodial passkey wallet for fintech and Web3 apps — no API keys, no MAU fees, no vendor lock-in. |
| **[Gas Abstraction Relayer](https://www.1shotapi.com/solutions/gas-relayer)** | Permissionless JSON-RPC relayer for EIP-7710 delegated transactions — sponsor gas or let users pay in stablecoins they already hold. |
| **[Developer Platform](https://www.1shotapi.com/solutions/devplatform)** | Server wallets, prebuilt contract skills, unified transaction dashboard, and real-time webhooks for agents, neobanks, and money flows on EVM. |
